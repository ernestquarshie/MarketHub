# MarketHub

A multi-vendor **B2C + B2B marketplace**: Amazon-grade retail shopping combined with Alibaba-style bulk sourcing (tiered pricing, MOQ, RFQ, supplier messaging), plus local payment and delivery options for Africa and global card payments.

> Portfolio / demo build. All payments run in **test mode**.
